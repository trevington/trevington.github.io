FSAE Powertrain Simulation & Optimization

Published: September 13, 2026 • Categories: Simulation, EV Powertrain

Overview

Building on the work of several graduating seniors, I developed a full vehicle powertrian simulator for CR31, Cyclone Racing's 31st car and 3rd EV. The simulation is built using Python and can be scripted and optimized.

Design Criteria

  • Map powertrain losses
  • Optimize powertrain use across all dynamic events
  • Determine heat rejection requirements
  • Use data from CR30 to validate simulations
  • Provide quick results (~1 second per endurance lap on a student laptop)

The lightweight requirement was a heavy constraint, as this project was my first time being performance constrained.

Simulation Architecture

Firstly, I made a list of all the major causes of losses in the powertrain system. For the simulation to be accurate, all loss calculations would need to be checked by other powertrain engineers.

The sim architecture (the fifth concept attempted using Gemini prototypes) was selected to decouple the physics simulations (motor.py and vd.py) from the overall sim. This allows engineers to reveiw more sizable portions of the code.

Validation

Unfortunately the whole-vehicle simulation validation plan ended when our inverter failed while testing CR30 in the Summer.

Since we couldn't acquire any new validation data, the only data available to me was from our early Summer testing logs. The 512mb of data was limited to short accelerations instead of full endurance runs, making heat generation validation difficult.

Results

The project is ongoing, so the "results" are hard to quantify. We did use the simulation to size the tractive battery, and removed 10 cells (2.7kg of weight).
